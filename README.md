# wup-osm — OpenStreetMap venues for WUP Travel

**© OpenStreetMap contributors.** The data in `osm/` is from
[OpenStreetMap](https://www.openstreetmap.org/copyright) and is available
under the [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
Each `osm/<city>.json` is a derivative database of OpenStreetMap, published
by WUP Travel ([wuptravel.com](https://wuptravel.com)) together with the
method below that rebuilds it, as the ODbL asks. The licence of the data is in
[`LICENSE-DATA`](LICENSE-DATA); see
[openstreetmap.org/copyright](https://www.openstreetmap.org/copyright).

This repository is where the files live and how they are made. WUP Travel's
`osm_import` step reads each city's file from here
(`https://raw.githubusercontent.com/Grapejuice-io/wup-osm/main/osm/<city>.json`)
for its vegan, dogs and LGBTQ+ pages. Nothing here touches a database, and no
secret is used.

## What each file holds

One file per city, `osm/<city-slug>.json`:

- `region`: the [Geofabrik](https://download.geofabrik.de/) extract it was
  cut from, and `extract_timestamp`, that extract's own replication time.
- `bbox` and `radius_km`: the box cut around the city's point, `radius_km`
  on each side.
- `venues`: every object in the box that matches the filter below, each with
  its OSM type and id, `name` and every `name:xx`, one point (a node's own;
  for a way or a relation, the middle of its bounding box), the tags that
  matched, `category` (its `amenity`, `shop`, `leisure`, `tourism`, `craft`,
  `club` or `natural` tag), the latest `check_date*` it carries, and the themes
  the matched tags put it in.

Nothing else from OpenStreetMap is kept, and nothing in these files comes
from any other source.

## The filter

`src/venues.ts`, and nowhere else:

- **vegan:** `diet:vegan=only` or `diet:vegan=yes`;
- **dogs:** `dog=yes`, `dog=leashed` or `dog=unleashed`; any `dog:conditional`;
  `leisure=dog_park`;
- **LGBTQ+:** `lgbtq=primary`, `lgbtq=welcome` or `lgbtq=only`.

## The method

Monthly (the 3rd, 04:17 UTC), by `.github/workflows/osm-extracts.yml`, for
each region:

1. download `https://download.geofabrik.de/<region>-latest.osm.pbf`;
2. for each city in it: `osmium extract -b <minlon,minlat,maxlon,maxlat> -s complete_ways`;
3. `osmium tags-filter` with `nwr/diet:vegan=only,yes nwr/dog=yes,leashed,unleashed nwr/dog:conditional nwr/leisure=dog_park nwr/lgbtq=primary,welcome,only`;
4. `osmium export -f geojsonseq --add-unique-id=type_id`, then keep the
   objects whose own tags match (a way's other nodes are exported with it and
   dropped here);
5. write the file only when its venues, region, box or radius changed.

The cities and their points are `data/cities.json`, the regions
`data/regions.json`, the radii `data/config.json`; the code is `scripts/`
(`extract.sh`, `cli.ts`, `lib.ts`) and `src/venues.ts`. What the last run
read, per city and per download, is `docs/osm-coverage.md`. A venue missing
from a later file is taken off WUP Travel's pages, never kept from an old one.

## The file format

The format is the contract with WUP Travel, which keeps only its parser.
`tests/fixtures/contract-city.json` is generated by this repository's code
(`bun scripts/cli.ts fixture`) and copied into WUP Travel's tests, whose
parser must read it. Change the format here and the fixture goes with it.

## Working here

`bun install`, then `bun run verify` (typecheck and tests). The scripts
themselves need no install: the workflow runs them with Bun alone.

The extracts identify themselves to Geofabrik as
`WUP Travel OSM extracts; https://wuptravel.com; https://github.com/Grapejuice-io/wup-osm`.
To reach us about them, open an issue in this repository.
